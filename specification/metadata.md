# N3X Metadata

Metadata is optional in N3X 0.1.

Recommended fields:
- `title`
- `creator`
- `application`
- `creation_date`
- `license`
- `source_format`
- `source_filename`
- `units`
- `coordinate_system`

Implementations SHOULD preserve metadata during conversion where the target format supports it.

Metadata MUST NOT be interpreted as proof of ownership, authenticity, or manufacturing quality unless a future specification defines those semantics.
